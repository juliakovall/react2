# Lesson 58

## Description

This project demonstrates secure cryptographic functions using the built-in Node.js `crypto` module.

## Features

- SHA-256 hashing
- PBKDF2 password hashing
- Password verification
- Timing-safe comparison
- Random salt generation

## Technologies

- JavaScript ES Modules
- Node.js
- Crypto API

## Installation

```bash
npm install
```

## Run

```bash
npm start
```

## Functions

### generateHash()

Generates a SHA-256 hash.

### generatePasswordHash()

Generates a secure password hash using PBKDF2.

### verifyPassword()

Checks whether the entered password matches the stored hash.
